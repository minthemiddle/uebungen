Übungen als self-contained single-file HTML + CSS + JS.
Übungen haben Titel ("Präpositionen")
Übungen haben Metabeschreibung (Datum der Erstellung, Tags-komma-separiert)
Übungen sind immer Lückentext.
Lücken sind zu Beginn nicht angezeigt.
Lücken können einzeln aufgedeckt werden.
Lücken können bewertet werden (Richtig oder Falsch beantwortet).
Status und Ergebnis wird in LocalStorage verwaltet (Angezeigt? Bewertet?)
Es gibt unter Übungen Reihe von Aktionen:
Innerhalb von Übungen kann Reihenfolge durch Buttonklick zufällig sortiert werden.
Alle Lücken können auf einmal angezeigt werden.
Status und Ergebnis kann zurückgesetzt werden.
Es gibt eine Übersichtsdatei (HTML) mit Tabelle aller Übungen mit Titel, Datum, Tags und Verlinkung.
